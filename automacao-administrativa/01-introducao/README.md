# Automação Administrativa

Material da disciplina de **Automação Administrativa** para o 2º ano de Administração.

A disciplina desenvolve o uso de ferramentas digitais para reduzir tarefas repetitivas, organizar dados e produzir informações úteis para a gestão.

## Organização do material

| Pasta | Conteúdo |
| --- | --- |
| [01 — Aulas](01-aulas/) | Roteiros e arquivos usados durante as aulas. |
| [02 — Atividades](02-atividades/) | Exercícios e práticas para realizar. |
| [03 — Avaliações](03-avaliacoes/) | Trabalhos e materiais avaliativos. |
| [04 — Materiais de apoio](04-materiais-de-apoio/) | Bases de dados e planilhas de apoio. |
| [05 — Terceiro trimestre](05-terceiro-trimestre/) | Material organizado por encontro do 3º trimestre. |

## Percurso da disciplina

1. **Fundamentos de automação:** identificar tarefas repetitivas e oportunidades de melhoria.
2. **Planilhas eletrônicas:** organizar, tratar e analisar informações no Excel.
3. **Power Query:** importar e transformar dados de forma reproduzível.
4. **Programação e IA:** avançar para automações de processos mais completos.

> Os arquivos de dados ficam próximos às respectivas aulas ou em **Materiais de apoio**. Preserve os nomes e as colunas das bases, salvo orientação da atividade.
