# Sobre a disciplina

Durante este curso aprenderemos como utilizar tecnologia para reduzir trabalhos repetitivos.

Começaremos com o Excel, depois aprenderemos programação em Python e, por fim, utilizaremos Inteligência Artificial para automatizar processos completos.

Nosso objetivo não é decorar ferramentas.

Nosso objetivo é aprender a resolver problemas.

---

# Onde queremos chegar?

Imagine que uma empresa precise:

- organizar centenas de planilhas;
- cadastrar milhares de clientes;
- gerar relatórios diariamente;
- organizar documentos automaticamente;
- enviar centenas de e-mails;
- descobrir quais produtos venderam mais.

No início do curso faremos tudo manualmente.

Ao final do ano construiremos programas capazes de fazer essas tarefas automaticamente.
